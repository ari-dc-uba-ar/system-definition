Contrato fijado:

1. firma pública `compileDraft(draft, runtime): Promise<ValidationResult<CompiledAuthoringInfo>>` junto a `MigrationDraftInfo`/`AuthoringRuntime`/`CompiledAuthoringInfo`;
2. `compileDraft` reconstruye `base.from`, carga el SSOT explícito `base.to` y usa `inspectDraft` para observar los efectos ya autorados antes de calcular el residual; historia, desired e inspected siguen siendo autoridades distintas;
3. `draft.changes` no es autoridad: se recalcula el diff residual entre el esquema inspeccionado y desired. Si un efecto autorado ya materializó un cambio, ese `changeId` no vuelve a generarse; sólo se emiten operaciones para diferencias que siguen faltando;
4. un residual `preserving` (por ejemplo ADD nullable) puede convertirse en operación estructural determinística; dos compilaciones iguales producen el mismo plan y desired ya alcanzado produce `operations=[]`;
5. un residual `requiresDataCheck` no inventa relleno ni prueba: vuelve a pending con `migration.authoringPending`;
6. un residual `unsupported` bloquea con `migration.unsupportedSchemaFeature`; nunca se omite para aparentar convergencia.

El rojo esperado es de compilación por un único módulo de producción intencionalmente inexistente: `../src/authoring`. No deben aparecer errores secundarios de `implicit any`.
