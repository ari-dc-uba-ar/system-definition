## Implementación

Después de esa aprobación se agregó `src/common/system-snapshot.ts` y se exportó desde `src/common/index.ts`.

La implementación:

- deriva la captura desde las Def existentes usando `completeEntity` y `completeRecord`;
- conserva `EntityInfoOf`/`RecordInfoOf` en `SystemSnapshotInfoOf`, `formatVersion: 1`, el literal de `systemId` y `{}` cuando `records` se omite;
- copia primero el input de captura con T01 para no ejecutar accessors de Defs externos ni conservar aliases;
- completa entidades/records y pasa el resultado por el mismo decoder runtime que usa JSON importado;
- captura sólo `Object.keys(context.types)`, nunca `tsType`, completers ni behaviours;
- exige en decode forma top-level normalizada, fields con key/name concordantes, tipos declarados, PK no vacía/existente/NOT NULL, UK no vacías/existentes y FKs normalizadas cuyo destino sea una PK o UK completa sin targets repetidos;
- devuelve una copia JSON desligada y reutiliza `migration.invalidJson`, `migration.unsupportedFormat` y `migration.invalidReference`.
